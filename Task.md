## Task
The files in the data folder contain the results of an RNA-seq experiment in in which CDK4 expression was suppressed using a siRNA. This gene regulates cell division and is an targeted in many cancer treatments.  
Explore the data in this repository’s data folder and read the descriptions provided in the various .md files (beginning with README.md). Then write a short report in a Word document with figures. that include information on: 
The quality of the RNA-eq data.  
A summary of the changes in gene expression due to CDK4 suppression. For example  
- the total number of genes analysed 
- the number of differentially expressed genes  

Highlight genes whose expression changes are relevant to CDK4 function or cell cycle regulation.  
- DK4 itself is an obvious starting point.  
- Searching online (Google or AI) for genes that interact with CDK4 will help you identify additional candidates.  
- For each gene of interest, include information suc as,  expression level, fold change, and statistical significance. (Remember: The genecounts.zip file contains expression graphs that may be useful.)  
- Similarly, examine the GO term, Reactome, and KEGG enrichment result files and identify pathways whose activity is significantly altered and could be linked to CDK4 suppression and cell division. Remember: the Kegg_Pathway_DeSeq2.zip file contains KEGG pathway images, which are often included in reports.
